Alpha 5.0 is Wave 1 PTU

RSI’s November 13 notes identify 5.0.0-PTU.13189690 for Wave 1 testers. PTU is a testing environment with separate access. Creating an account with a referral code does not grant PTU access.

The developer tracker also notes that the Time To Kill balance pass in this test build is not currently intended for the 5.0 release. Treat test-build features as testing information, not a guarantee of release content.
