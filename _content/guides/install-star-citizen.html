Quick answer

Download the current launcher from RSI, sign in to the account with game access, choose the public LIVE environment, and install on an SSD. If an existing installation disappears from the launcher, check its configured path before downloading everything again.

Before you download the launcher

Check your PC requirements and SSD space first. Outside an eligible Free Fly, your account needs a Star Citizen game package. An owned standalone ship and a game package are different products; the package guide explains what to look for.

Use the download link in RSI’s official installation instructions. This avoids relying on an installer linked from an old forum post. Keep the account you use for the website and launcher consistent.

Install the public game

  1. Install the current RSI Launcher. Open it and sign in with your RSI credentials. Complete the account’s authentication prompt if one appears.
  2. Choose LIVE. This is the public game environment. PTU, EPTU and other testing channels have their own access and installation requirements.
  3. Check the installation destination. Confirm that the selected game location is on the SSD you prepared, with sufficient free space.
  4. Start installation and let it complete. Do not treat an installer or launcher download as the full game download.
  5. Launch a short first session. Confirm that the game opens before arranging a group session or a long trip.

The launcher’s Games settings contain environment-specific paths and file-verification controls. Its Download settings contain bandwidth and concurrent-download options. Those locations are documented in the official installation article; use the labels shown by your installed launcher if its presentation changes.

The launcher says the game is not installed

Start with the install path. RSI documents that a path which does not match the actual game folder can make the launcher believe the game is absent. This is particularly relevant after moving files to another drive.

CheckWhat you are comparing
EnvironmentThe selected LIVE or test channel, not just the game title.

Actual folderThe location where that environment’s game files are stored.

Make a note of the existing location before changing settings. Repeatedly switching channels and destination folders makes it harder to understand which copy the launcher is using.

Download stuck or files failing verification?

RSI’s launcher troubleshooting guide includes the built-in Clear Launcher Cache action, drive-space checks, and error-specific advice. Its installation guide also explains file verification. Start with these targeted controls rather than immediately deleting the installation.

Write down the exact error and which stage failed: signing in, fetching the manifest, downloading, verifying, or starting the game. If you need further help, that distinction is much more useful than “the launcher is broken.” Keep private login details out of screenshots or public reports.

Do I need the 5.0 PTU download?

Not for a normal public first session. PTU is a separate test environment. Check our dated release snapshot and RSI’s PTU access rules if you deliberately want to test it. A referral link does not unlock a test wave.
