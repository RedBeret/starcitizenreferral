Quick answer

Open Options → Keybindings, choose the correct peripheral, and use Advanced Controls Customization to inspect or change actions. Export a working profile before experimenting with another setup.

Select the device you intend to configure

RSI’s peripheral setup guide documents the device selector, advanced customization and supplied Control Profiles. Keyboard, mouse and joystick bindings can belong to different device views.

Start by finding one action you can recognize, such as landing gear. Read its current assignment before changing it. This gives you a known reference when comparing a written guide, a controller diagram and the controls on your desk.

Change one action and check conflicts

  1. Choose the peripheral in the Keybindings screen.
  2. Open Advanced Controls Customization and locate the action.
  3. Read the existing binding and any relevant action mode.
  4. Use the on-screen binding prompt to assign the input.
  5. Review conflicts before accepting the result.
  6. Test the action somewhere appropriate before continuing with more changes.

The official instructions describe right-clicking to unbind and double-clicking to capture a new input. Use the current screen’s prompts if the presentation differs. A button that already controls another action needs a deliberate decision; dismissing a conflict without reading it can create a second problem.

Export a profile you can restore

The official profile guide explains Save Control Settings and the exported XML file. Use a name that identifies the device arrangement and the setup you just tested.

Keep a separate copy of the export before a reinstall or a major experiment. Saving a screenshot of a binding diagram is useful for reference, but it is different from saving the actual profile file needed for import.

Importing another player’s profile

Match the profile to your device model, device order and intended game version. RSI describes placing profile XML in the game’s Controls/Mappings location and selecting it through Control Profiles. Use its current article for the exact installation path rather than assuming every player uses the default drive.

Read which device groups the import will change. A joystick profile may also offer keyboard changes. Compare those choices with the creator’s instructions, then inspect essential actions before launching a mission.
