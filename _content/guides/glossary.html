Quick reference

Use this glossary to decode common Star Citizen terms, then follow a linked walkthrough when you need the actual steps. Definitions describe the idea; current controls, availability and detailed rules belong in the relevant guide or official documentation.

Worlds and game environments

PU — Persistent Universe
The shared universe mode used for travel, missions and everyday play. “Persistent” in the name is not a promise that alpha progress can never reset.
LIVE
The generally available game environment. A LIVE build can still be part of alpha development.
PTU — Public Test Universe
A separate testing environment used to prepare releases. Check its access instructions rather than assuming it is always open.
AC — Arena Commander
A separate game mode for focused scenarios. Check which mode a tutorial means before following its ship or rental instructions.
Hab
Short for habitat: accommodation you may encounter at a landing location.

RSI’s getting-started guide introduces the universe, while the PTU FAQ explains the environment distinction.

Cockpit and flight language

ASOP terminal
The ship retrieval console. Read its assignment to find the correct hangar; see hangars and retrieval.
ATC — Air Traffic Control
The service you contact for landing or departure authorization. Follow the assignment and current clearance instructions.
HUD — heads-up display
Information presented over the pilot’s view, such as flight state or markers.
MFD — multifunction display
A cockpit screen used to show a selected ship system or information page. Different ships arrange them differently.
QT — quantum travel
A travel system for covering large distances. The quantum guide separates route preparation from initiating travel.
Strafe
Move sideways or vertically without turning the ship to face that direction. It is different from rotating the ship.

Money and access

aUEC
Alpha United Earth Credits, used for the alpha’s in-game economy.
UEC
United Earth Credits, the account currency intended for the released game.
REC
Rental Equipment Credits, used for eligible Arena Commander rentals.
Store credit
A website balance for eligible RSI pledges, distinct from an in-game wallet.
Game package
A pledge that includes game access and listed contents. A standalone ship is a different pledge type.

The currency comparison explains balance questions. Check RSI’s pledge documentation for access and package contents.

Equipment and people

Loadout
The equipment selected for a character or ship. Owning an item and equipping it are separate questions.
Local storage
Items stored at a particular location. Check the location as well as the item name when searching inventory.
Party
A group formed for playing together. Agree on a meeting place as well as forming the group.
Player guide
A person teaching through the official Guide System. This differs from a written article such as this glossary.
Issue Council
RSI’s bug-reporting platform. Search for a matching report before creating another.
