Quick answer

A Star Citizen Free Fly temporarily opens game access under an official event’s terms. You still need an RSI account, a suitable PC and the download. A referral code and an event-access code serve different purposes.

Check the announced event first

IAE 2956 · November 2026

For the event checked on 15 November 2026, RSI advertises IAE free play from November 13 through November 27, at New Babbage. The announcement says no special event code is required.

Read the official IAE access terms ↗

Read the event that is actually running. Dates, access steps and loaned ships can differ between Free Fly periods. Do not assume that a redemption code from a previous festival is needed for a new event.

How to prepare for a Free Fly

  1. Check the dates and eligibility. Use the official event page and note when access ends.
  2. Check your PC. Free access still requires a machine and SSD that meet the published specifications.
  3. Create or use your RSI account. Follow the access steps in that announcement. If you are creating a new account, choose a referral code before completing signup.
  4. Install the current launcher and game. Follow the installation checklist and allow time for the full download.
  5. Plan a short test session. Learn the route to your ship before trying a long mission chain.

Referral code versus event code

The standard player referral code on this site is STAR-9L66-ZTDY. It belongs in the new-account referral field. It is not a universal Free Fly activation code, a package discount or a PTU invitation.

RSI’s current IAE announcement says no special event code is needed for that Free Fly. For other events, follow their own instructions. The referral rules explain the standard 50,000 UEC benefit and the account-creation window; no extra referral reward is promised here.

Make the trial useful

Give the session a concrete objective: load in, reach your ship, make a short flight and return. Record your starting city and the part you want to evaluate. That makes it easier to decide what felt enjoyable, confusing or technically difficult.

If you start at New Babbage, use the first-flight guide. If you are trying the game with a friend, arrange the party and meeting point before spreading out across different locations.

What happens when the Free Fly ends?

Temporary access and event loaners should not be treated as permanent purchases. The IAE announcement specifically describes its Aurora access as lasting for the event. Check a game package’s actual contents if you later decide to buy access.

A sensible follow-up is to write down what you still need to learn before spending more: performance on your PC, whether you enjoyed the basic travel loop, and which activities you want to try next. See the game-package guide when you are ready to compare the live listing.
