04 / A clear approach

Good questions.
Straight answers.

Referral codes are simple. The details are worth checking before you create an account.

Check the link yourself ↗
What does a Star Citizen referral code give me?

The standard new-account referral bonus is 50,000 UEC. Use a valid code when creating your RSI account. Check the current signup page for the reward and package terms.

Is this a discount on a game package?

No. A referral code adds the standard credit bonus; it does not reduce the checkout price or include an extra ship. Game access and event offers have their own terms.

I already made an account. Can I add the code?

RSI allows a 24-hour grace period if you omitted a code. Sign in, open your account summary from the user icon, and look for the referral field near the bottom. An existing referral cannot be replaced.

Who benefits when I use this code?

STAR-9L66-ZTDY belongs to PatchOps. RSI awards the owner a recruitment point when a referred player obtains a game package and meets its qualifying $40 USD pledge requirement.

Is this the official Star Citizen website?

This is an independent fan site by PatchOps. Account creation and purchases happen on the official Roberts Space Industries website. We never ask for your RSI password.
